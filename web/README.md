# Game of Life — Polyglot Learning Lab (`web/`)

Interfaz web interactiva para aprender **TypeScript**, **TypeScript + React** y **Golang** tomando como referencia directa el diseño original en **Java**.

## Cómo abrirla

No requiere compilación ni dependencias externas:

- **Opción 1 (directa):** Abre `web/index.html` directamente en tu navegador (`open web/index.html` en macOS).
- **Opción 2 (servidor local):**
  ```bash
  node web/server.mjs
  ```
  Y abre `http://localhost:3030`.
